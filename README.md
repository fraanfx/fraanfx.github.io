# Personal Portfolio  

🚀 My personal portfolio built with **HTML, CSS, and JavaScript**.  
This project showcases my work, skills, and projects in a **lightweight, fast, and accessible** way.  

🌐 Live demo: [fraanfx.github.io](https://fraanfx.github.io/)  

---

## ✨ Features  

- ⚡ **Lightweight & Fast** – no heavy frameworks, just pure **HTML, CSS, and JS**.  
- ♿ **Accessible** – follows **WAI-ARIA** guidelines for better usability.  
- 🔍 **SEO-Friendly** – optimized structure and metadata for search engines.  
- 📱 **Responsive Design** – looks great on desktop, tablet, and mobile.  
- 🎨 **Clean UI/UX** – simple, modern, and user-friendly interface.  

---

## 📂 Tech Stack  

- **HTML5** – semantic structure  
- **CSS3** – modern styling and responsive layout  
- **JavaScript (ES6)** – interactivity and dynamic content
